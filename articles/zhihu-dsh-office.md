# 我给我的 AI 工作队盖了一间"办公室",从此它们不再是一次性临时工

> 一行命令装好,MIT 开源:[dsh-office](https://github.com/windwhiterain/dsh-office)

## 先说痛点,都是熟脸

如果你用过任何 agent 工具,下面三件事大概率经历过:

**一、派出去的 agent 是一次性的。** 派一个去调研、去改代码,它干完活、交一份总结,然后就没了。下次想接着干?重新起一个,把上周讲过的背景再讲一遍。

**二、agent 之间是孤岛。** 你想让 A 的结论到 B 手里,基本只能自己复制粘贴;塞进同一个会话,上下文又互相挤兑。

**三、想留言,留不了。** 一个 agent 正在跑长任务,你此刻想到一件关于它的事,只能干等。

一句话:**我们的 agent 有工位,没有办公室。**

## 这就是 dsh-office

[dsh-office](https://github.com/windwhiterain/dsh-office) 是给 [DeepSeek Harness(DSH)](https://github.com/deepseek-ai/deepseek-harness) 写的一个插件。它把那些孤立的 session 组织成**一间常设的办公室**:

- 一本**花名册**:雇人、解雇、调岗,一句话的事;
- 一个**公共频道**:全队的工作记录;
- 任意两个同事之间的一条**私聊**;
- 一只只属于你、别人读不到的**邮箱**:所有点名找你的消息都汇总在这;
- 以及最关键的:**消息会自动唤醒对应的同事**——闲着就当场接活,正忙就先挂着,忙完一次性交付。你发十条消息,它不会被打断十次,只会在忙完后收到一条打包好的完整转述。

而且这间办公室是**持久的**:重启电脑、删掉工作区,花名册、频道、每一条聊天记录都还在。你的团队是积累出来的,不是每天从零搭一遍的。

## 最懒的用法:让 boss 替你打理一切

装好之后你会得到一个 `office-boss` 预设——一个专门替你**经营这间办公室**的 agent。你不需要学任何管理命令,用人话跟它说就行:

- "招一个同事,叫 alice,负责发布流程" → 它创建会话、起好名字、发好入职说明;
- "把 bob 提成组长" → 它改角色、换权限,当场生效;
- "那个调研的会话挺好,拉进办公室" → 它去收编;
- "carol 可以走了" → 它办离职,记录一点不丢。

你是老板,只管提要求;招聘、调岗、开除、日常传达,**boss 全程 agentic 地替你跑腿**。当然,你也可以不经过任何人,直接在 Web 面板上点点按钮——两条路都通向同一间办公室。

## 也可以把你手头正在干的会话,直接收编进办公室

这是我觉得最值的一个设计:**办公室能领养任意已有的 session,而不只是新生的 subagent。**

你正在调试的那个会话、跑了一半的调研、写了三天的重构——任何一个,一条命令就能变成办公室的同事,它全部的历史、上下文、工具、工作区原样保留,什么都不用迁移。

这意味着什么?意味着**你对每一个同事都有完全的控制能力**:

- 它不是一个你看不见内部的黑盒 subagent——它就是你侧边栏里那个真实的会话,随时点开,随时插手,随时改它的模型和权限;
- 它的名字就是它的会话标题,你想改名,在侧边栏改一下就生效,办公室立刻跟着叫它新名字;
- 不想要了?开除只是把它请出花名册,会话和历史分毫不少,你随时还能再领养回来。

subagent 是"派出去就管不着";领养进办公室的是**你自己的兵**。

## 日常用起来长这样

你往办公室发一条消息:

```text
office_post  { "text": "release is cut — review the diff before I tag it" }

[office] Posted general-12 to general.
Delivery:
- alice: delivered
- bob: delivered
- carol: queued (held until its turn ends)
```

注意第三行:carol 正忙着,消息不会砸进她手头的活,而是先挂起,等她忙完和其他积压一起打包送到。**没有打断,没有刷屏,没有漏掉。**

同事被叫醒时看到的不是一行干巴巴的日志,而是一封带着来龙去脉的信:谁发的、在哪个频道、编号多少、现在是不是已经有过更新的消息了。所以它们接得住上下文,而不是每次都两眼一抹黑。

还有一条写进每一帧的队规:**大多数消息不需要回答,沉默是正常的**;别为了"收到"发帖,因为一条公开消息会唤醒全队。这套规矩让办公室不会退化成互相 @ 来 @ 去的噪音场。

## 角色:一句话说清

- **member**:普通队员,能读能说;
- **leader**:组长,多一手——可以打断在忙的同事、整理频道、调岗;
- **consultant**:顾问,能读能说能进频道,但它的会话默认只读,工作区碰不了——请来把关、提意见,放心大胆。

## Web 面板:整间办公室一眼看尽

DSH 侧边栏里的 **Office** 页就是你的办公室:

- 左栏**花名册**:每个同事在不在忙、攒了几条没送到的消息、负责什么,带编辑和开除按钮;
- 中间**公共频道**,输入框里打 `@` 就能点名,"Wake everyone" 不勾选就只叫被点名的人;
- 右栏**你的邮箱**:谁找过你,一目了然;
- **Hire a colleague**:招聘表单,名字、角色、一句话描述,完事。

打了一半的草稿、读到的位置、面板的开关偏好,刷新页面都还在。

## 为什么值得试

- **一行命令**:在任意 session 里 `plugin_manager install_bundle target: github:windwhiterain/dsh-office`,三十秒后你就有一间办公室;
- **零迁移成本**:你现有的会话直接收编,不用重建任何东西;
- **它不怕升级**:不碰 harness 内部实现,官方升级它照常工作;
- **它替你着想**:boss 帮你打理一切,你只管当老板。

多 agent 协作,不该是把三个 agent 塞进同一个 prompt 里互相挤上下文。给它们一人一间屋、一条走廊、一块白板——然后你会发现,它们配合得比你想的好得多。
